# Basic German: A Grammar and Workbook — справочник

Heiner Schenke, Karen Seago. *Basic German: A Grammar and Workbook*. Routledge, 2004. 28 юнитов, 215 страниц.
Источник — `courses/Basic german.pdf`, разрезан по юнитам (`pdftotext -layout`, лигатуры нормализованы, колонтитулы сняты).

**Что это и что не это.** Это **справочный источник** для авторов теории немецких курсов — эталон того, насколько подробно объясняется грамматика A1–A2 и сколько примеров на пункт. Это **не контент курса**: файлы не синкаются в БД, `COURSE_ROOTS` (`web/content.config.ts`) их не видит, каталог `_reference/` намеренно вне курсовых. Текст лежит в код-блоках, чтобы сохранилось колоночное выравнивание парадигм.

**Как пользоваться.** Пишете `theory.yaml` модуля — открываете юнит из колонки «Юнит» ниже, берёте оттуда парадигму целиком, набор примеров и разбор частных случаев. Правило опоры (`PLAN.md` §1a курса) при этом не отменяется: юнит даёт материал, план решает, что из него модуль вправе потребовать.

## Оговорка

Книга 2004 года и написана для англоязычного читателя. Что из неё **не** переносится дословно:

- **Метаязык.** de-a2 — полное погружение (`PLAN.md` §5): английские объяснения книги там нельзя использовать, только парадигмы и примеры. de-a1 английские леса разрешает — но graded под A1, без книжного «finite verb», «modifier», «interrogative».
- **Правило опоры.** Юнит объясняет тему целиком; модуль курса берёт из неё ровно ту часть, что объявлена в `PLAN.md` §4.
- **Орфография.** Дореформенные варианты в книге встречаются редко, но `daß`/`muß` в цитатах проверять.
