# Шаблон ТЗ субагенту — генерация модуля

Перед запуском: карточка модуля берётся из `docs/PLAN.md` (раздел «Роадмап», М{N}), схема пакета — из `content/en-c1/README.md`.

## Промпт

```text
Разработай модуль M{N} курса en-c1 по спецификации из docs/PLAN.md
(карточка модуля M{N}: тема, грамм-подтемы, домены лексики с якорями,
названия текстов, жанр продукции) и схеме пакета content/en-c1/README.md.

ЯЗЫК: весь контент — строго английский, graded под B2+ (стиль Cambridge-учебника
и learner's dictionary). Ни одного русского слова ни в одном файле.

Сгенерируй пакет файлов content/en-c1/module-{NN}/:
1. meta.yaml — тема, подтемы грамматики (grammar_points), standfirst, goals (каждая цель — объект `{text, achieved_by}`: грамматические цели → `workout`, лексическая → `input`, продукционная → `output`)
   (3–4 can-do), тексты, жанр продукции.
2. vocab.yaml — ПОЛНЫЕ 45 записей (якоря из плана + добор в тех же доменах,
   уровень C1, не частотник B1): term, tag, definition, use_cases (2–3 в разных
   контекстах), collocations, register.
3. theory.yaml — grammar spotlight (title, intro, items: form / example / note
   по всем подтемам) + watchouts (частотные ошибки, отбор — L1-интерференция)
   + cloze_cards: 10 грамматических cloze-карточек (text с {{c1::…}}, hint,
   rule) по подтемам модуля.
4. text-main.yaml — лонгрид под заявленным названием: ≥20 единиц из vocab.yaml,
   ≥8 целевых конструкций, аутентичная журналистика C1; body — сегменты
   {t: "…"} | {g: gloss_key}; glosses: 3–5 записей (term, pos_label,
   definition, example).
5. text-extra.yaml — второй текст заявленного жанра, ≥8 единиц.
6. exercises.yaml — основной сет ровно: 8 mc_cloze, 8 open_cloze,
   8 word_formation, 8 key_word_transformation, 10 grammar_drill,
   8 error_correction, 10 collocation_match, 6 reading_comprehension;
   плюс review_pool: 30 смешанных коротких заданий. Формат content каждого
   типа — как в docs/design/skyrocket/content.js (exercises). У каждого:
   answer + explanation (English). Ровно один верный ответ. group_key:
   grammar | reading | vocab. 2–3 трансформации — на грамматику прошлых
   модулей (спиральное повторение). Индексы верных ответов (answer у
   mc_cloze / grammar_drill / reading_comprehension, wrong у
   error_correction) РАСПРЕДЕЛЯТЬ равномерно по позициям — никаких серий
   из 3+ одинаковых индексов подряд и никакого «правильный всегда первый».
   ПРОПУСК ОБЯЗАН БЫТЬ ВОССТАНОВИМ. В open_cloze пропуск падает на служебное
   слово (предлог, союз, артикль, вспомогательный, модальный) или на голову
   устойчивой рамки — тогда подсказка не нужна, это формат CAE Part 2. Если
   на месте пропуска знаменательное слово, выбранное лексически, `hint`
   ОБЯЗАТЕЛЕН и содержит словарную базовую форму (`hint: know` для knowing),
   а не название части речи. Если грамматика задаёт класс, но не слово —
   перечислить в `answers` весь класс (≥4). И в любом типе `answers` содержит
   ВСЕ валидные варианты: пропущенный синоним — это ложная ошибка в грейдинге.
   Правило см. в content/en-c1/README.md, оно проверяется sync'ом.
7. writing.yaml — задание CAE-жанра (mode: writing или speaking по плану),
   prompt, model answer 220–260 слов, self-check checklist из 8 пунктов.

Флеш-карточки отдельно не пишутся: sync деривирует из vocab.yaml две карточки
на запись (узнавание term→definition и воспроизведение definition→term, 90 на
модуль). Колода — только лексика. cloze_cards из theory.yaml становятся
упражнениями open_cloze в review-пуле, а не карточками, поэтому hint пиши как
подсказку-основу для ответа (базовая форма глагола), а rule — как разбор.

Definition of Done — чек-лист ниже; каждый пункт проверить перед сдачей.
```

## Definition of Done

- [ ] Ни одного русского слова в файлах модуля; определения и объяснения — graded English (learner's dictionary style).
- [ ] 45 записей vocab.yaml уровня C1: коллокации и фразовые глаголы, не одиночные частотные слова; у каждой — definition, 2–3 use cases в разных контекстах, collocations, register.
- [ ] Лонгрид содержит ≥20 целевых единиц и ≥8 целевых конструкций; читается как аутентичная журналистика, не как упражнение; глоссы расставлены.
- [ ] 66 основных заданий + 30 в review_pool; счёт по типам сходится; у каждого ровно один верный ответ и объяснение на английском; формы content соответствуют типам плеера.
- [ ] Индексы верных ответов перемешаны: в каждом choice-типе (mc_cloze, grammar_drill, reading_comprehension) все позиции опций встречаются, серий из 3+ одинаковых `answer` подряд нет.
- [ ] Каждый `open_cloze` восстановим: служебное слово / устойчивая рамка — без подсказки; знаменательное слово — с `hint` в базовой форме; класс без конкретного слова — с полным набором `answers` (≥4). Прогнать глазами: «может ли сюда встать другое слово, которого нет в `answers`?»
- [ ] `answers` во всех типах со свободным вводом перечисляют все валидные варианты, включая очевидные синонимы (`allowed`/`permitted`/`supposed`, `essential`/`important`/`necessary`).
- [ ] `theory.yaml` содержит ровно 10 `cloze_cards` (text с `{{c1::…}}`, rule, hint — базовая форма ответа, обязательна) по подтемам модуля.
- [ ] Трансформации включают 2–3 задания на грамматику прошлых модулей (спиральное повторение).
- [ ] Модельный ответ writing выдержан в целевом регистре и укладывается в 220–260 слов.
- [ ] YAML валиден и соответствует схеме `content/en-c1/README.md` (поля для sync в БД).

## Порядок разработки курса

1. **Пилот:** диагностика + модуль М1 → пройти М1 самому от начала до конца, зафиксировать проблемы (сложность, объём, формат карточек), откалибровать DoD.
2. **Пачки по блоку:** после калибровки модули генерируются пачками по 4 (блок за раз), параллельными субагентами — каждому по карточке модуля из плана.
3. **Чек-пойнты:** тесты чек-пойнтов генерируются после завершения контента блока — отдельная задача со списком фактических правил и лексики блока.
